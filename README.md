# 课程助手 · B站课程实时总结（本地版）

一个不依赖 DeepSeek Harness 的本地小应用：双击桌面上的「课程助手」快捷方式，浏览器会打开一个控制台，自动检测浏览器前台的 B 站课程视频，抓取简介 / 字幕 / 弹幕 / 热评，生成知识点总结并导出 Word。

## 功能

- **应用开关**：一键暂停 / 恢复轮询。
- **轮询间隔可调**：3–300 秒，输入或点预设（5/10/15/30/60 秒），改完立即生效。
- **实时轮询界面**：当前前台窗口、判定结果（非浏览器 / 非课程 / 已处理 / 新视频）、最近 50 条观察记录、下次检测倒计时。
- **实时总结界面**：视频信息、课程概览、核心知识点、弹幕与评论焦点、关键词。
- **Word 导出**：每期视频一份 .docx（同目录还有 .md 源），支持打开 / 下载 / 打开所在目录。
- **笔记历史**：按学科筛选、点击回看、重新总结。
  - 「刷新」会扫描输出目录（`输出目录/学科/标题.docx`），把外部生成（例如 DSH 插件、手动拷贝）的笔记一并并入历史；导入条目标记为「目录导入」，可点「重新总结」重新抓取 B 站内容。
  - 「打开目录」优先调用系统资源管理器；如果当前运行环境不允许（受限/沙箱进程，explorer 会以 0xC0000142 立刻退出），会自动退回浏览器内的目录视图 `/folder`（可直接点开 docx/md）。
- **可选 AI 总结**：设置里填 OpenAI 兼容接口（默认 DeepSeek）即可用大模型总结；不填则用本地规则摘要。

## 启动

1. 双击桌面「课程助手」快捷方式（或运行 `scripts/launcher.vbs`）。
2. 浏览器自动打开 http://127.0.0.1:6520/。
3. 在浏览器前台播放 B 站课程视频即可。

再次双击不会起第二个进程：若 6520 已在本应用监听，只会把页面打开。

## 用链接访问

这个应用本身就是一个网页：启动后浏览器打开的就是 `http://127.0.0.1:6520/`，控制台即链接。默认只监听本机，别人打不开。需要分享给别人时有两种方式：

- **同一网络（同一 Wi-Fi）**：双击应用目录下的 `lan.cmd` 以局域网模式启动，把 `http://<本机IP>:6520/` 发给对方即可（本机 IP 用 `ipconfig` 查看，局域网模式下启动日志里也会提示）。注意防火墙首次可能弹窗，选择「允许访问」。
- **公网访问**：需要内网穿透工具（如 cloudflared、ngrok）把 6520 映射出去。默认不开启——那等于把本机的控制台、笔记文件、历史记录暴露到互联网上。

局域网模式下请在可信网络里使用：控制台没有登录鉴权，同网段任何人都能打开。

## 配置

页面「设置」里可改；也可直接编辑 `data/config.json`：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| enabled | true | 轮询开关 |
| intervalMs | 15000 | 轮询间隔（3000–300000） |
| notesDir | %USERPROFILE%\Documents\课程笔记 | Word 输出目录（首次运行自动创建） |
| autoOpenBrowser | true | 启动时打开浏览器 |
| llm.enabled | false | 是否用大模型总结 |
| llm.baseURL | https://api.deepseek.com | OpenAI 兼容接口 |
| llm.model | deepseek-chat | 模型名 |
| llm.apiKey | 空 | API Key（本地保存，接口返回时脱敏） |

没有 API Key 时使用本地规则摘要：从简介里抽要点、从弹幕/热评里统计高频主题。需要更高质量时再填 Key。

## 与 DSH 版的关系

- 输出目录与 DSH 插件共用；生成前会检查同名 .docx，已存在则直接复用，不覆盖。
- 两边状态各自独立（本应用用 `data/state.json`，DSH 插件用 `课程笔记/.state/notes.json`），可同时运行。
- 本应用不需要启动 DSH，也不读取 DSH 的配置或登录态。

## 常见问题

- **双击快捷方式没反应**：先看 `data/launcher.log`（记录每次启动/已运行判断/浏览器打开）；再看 `data/app.log`（服务端错误）。也可以直接双击 `scripts/launcher.vbs` 排查。
- **页面打不开**：先在浏览器访问 http://127.0.0.1:6520/api/state ；看 `data/app.log`；端口被别的程序占用时会明确报错。
- **检测不到视频**：仅识别前台浏览器窗口；B 站首页/搜索页会被忽略；后台标签页不行。
- **一直显示「错误 · 看不到任何窗口」**：应用读不到桌面窗口。双击应用目录下的 `diagnose.cmd`，会在同目录生成 `diagnose-report.txt`（含 Add-Type 是否成功、能枚举到几个窗口）。两种常见原因：① **临时目录不可写**，导致 PowerShell 编译读窗口的代码失败——新版本已自动把编译临时目录改到 `data\tmp`，重启应用即可；② 用**别的账户**的管理员身份、**任务计划/服务**、或**远程桌面已断开**的会话启动——换成当前登录账户双击桌面快捷方式。
- **Word 打不开**：`data/app.log` 里找生成错误；也可以先用「重新总结」重试。
- **想彻底移除**：退出应用，删除本目录和桌面快捷方式即可（不写注册表、不装服务）。

## 隐私

所有数据都在本机：配置、状态、生成的文档。开启 LLM 时，视频标题、简介、弹幕、热评会发送到你所填的接口。

## 快捷方式

- `make-shortcut.cmd`：双击运行，会在**当前这份目录**里定位启动器，并在桌面创建「课程助手」快捷方式（含图标）。
- 复制到别处、换机器之后，都用它重建一次——命令行里的路径是按目录本身算的，不依赖任何固定位置。

## 打包说明

- 本目录**不含** `data\` 目录：那里存着 `config.json`（可能含 API Key）、`state.json`（观看与生成历史）以及运行日志，属于个人数据，已随包剔除。首次启动会自动重建。
- 源码压缩包 `course-assistant-src.zip` **不含** `runtime\node.exe`（约 90 MB 便携 Node）；本目录副本自带，可直接运行。
- 不附带预制的 `.lnk` 快捷方式：Windows 快捷方式里会写入**本机计算机名**与绝对路径，换台电脑既打不开也会泄露信息。请用 `make-shortcut.cmd` 在本机生成。
- 源码里没有绝对路径依赖：启动器、快捷方式脚本都按自身位置定位应用目录。
